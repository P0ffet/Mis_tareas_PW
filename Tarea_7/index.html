Resumen HTML:Principales conceptos

Esta pagina va a resumir los principales conceptos y etiquetas vistas en la clase de programacion web 1, en el moodulo HTML

Conceptos principales HTML

HTML

El lenguaje de marcado de hipertexto es un lenguaje de marcas que se utiliza para estructurar sitios web

Elemento HTML

Un elemento HTML es la unidad basica de estrutura y contenido en una pagina web, y esta compuesta de dos puntos

  1. Etiqueta de apertura
  2. Pares atributos-valor
  3. Contenido
  4. Etiqueta de cierre

Etiqueta <Head>

Es una etiqeuta que se utiliza para comunicarse con el navegador a traves de los metadatos, permite mejorar el seo, ademas se enlazan archivos externos de estilos o scripts

Etiqueta <body>

Dentro de esta etiqueta va todo el contenido que ve el usuario en nuestra pagina web

Contenedores semanticos

<Head> Es una etiqueta utilizada para el contenido introductorio para una pagina web, puede contener el logo, el menu de navegacion principal, el nombre de la empresa etc...
<Nav> Etiqueta utiliza para el menu de navegacion principal, suele contener enlaces a otras paginas relacionadas o navegar por la pagina principal no debe de haber mas en la pagina
<Main> Etiqueta unica de una pagina web cuyo proposito es resaltar nuestro objetivo o mensaje principal del mensaje web, dentro se colocara el contenido principal de nuestra pagina
<Section> Es una etiqueta de poco a poco se intenta que sutituya a <Div>, su uso es para dividir a una pagina web en secciones y agrupar contenido relacionado
<Article> Es una etiqueta que se utiliza para agrupar contenido autonomo, que si se separa de otro contenido sigue teniendo coherencia, normalmente se compone de un encabezado y contenido
<Footer> Es una etiqueta que normalmente se encuentra hasta el final de una pagina web y funciona como cierre del sitio web a menudo contiene datos de contacto, derechos de autor u otra informacion complementaria
<Aside> Esta etiqueta representa una seccion de la pagina web, cuyo contenido no esta directamente relacionado con el contenido principal del documento, : barras laterales, publicidad, enlaces a otros articulos relacionados

Elementos principales de HTML

Elementos <a>

Este elemento contiene enlaces a otras paginas:

  • Externos
  • Internos
  • Anclaje

Algunos valores especiales que tiene en su atributo href son:

href="https://wa.me/123456789
Este valor envia a un whatsapp a un numero especifico
href=mailto:example@gmail.com
Envia un correo a un mail especifico

Elemento <form>

es la manera en que los usuarios pueden comunicar con una pagina web, gracias a este elemento se pueden procesar los datos de los usuarios segun el objetivo de nuestra pagina web
