Tipos de estilos en CSS

Estilos en linea

Esto estilos se van agregar directamente en el elmento html, mediante el atributo Style

Este parrafo tiene estilos en linea

Estilos internos

Estos estilos se agregan en el mismo archivo html dentro de la etiqueta head <Head> y para agregarlos se utiliza el elemneto: <Style>

Estilos externos

Estos estilos son los que se recomienda utilizar ya que ofrece modularidad, y facil mantenimeinto, orden, eficiencia , entre otras ventajas, para agregar una hoja de estilos externa, dentro de la etiqueta <Link>, donde se especifica la ruta de nuestra hoja de estilos
